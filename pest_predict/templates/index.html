About the Platform

PestPredict SP is a predictive geospatial platform designed to map and anticipate pest infestation risks across urban, agricultural, and forestry sectors in the State of São Paulo, Brazil.

By combining real-time meteorological metrics (temperature, relative humidity, and cumulative rainfall) with environmental dynamics and pest phenology, the model calculates regional outbreak probabilities for species such as Tityus serrulatus (Yellow Scorpion), Diatraea saccharalis (Sugarcane Borer), and forestry pests.

How Predictive Intelligence Works

1. Meteorological Fetching

Automated ingestion of real-time climate metrics via Open-Meteo API for key municipal hubs in São Paulo.

2. Bioclimatic Matrix

Python-based algorithm correlating temperature, humidity thresholds, and species reproductive parameters with land use.

3. GIS Rendering

Dynamic Leaflet.js mapping overlaying crop mosaics and susceptibility risk heatmaps onto regional base layers.

Implementation Highlights

  • Dual-Sector Scope: Independent modules tailored for Urban Integrated Pest Management and Agricultural/Forestry Protection.
  • Regional Mosaic: Spatial mapping across São Paulo's predominant land uses (Eucalyptus, Sugarcane, Soy, Maize, Citrus, and Urban Zones).
  • Heatmap Overlays: Custom incidence risk rendering using opacity layers over geographic boundaries.
  • IP Protection: Focuses on displaying geospatial risk prognosis and software analytical capabilities while safeguarding core proprietary logic.
