PestPredict SP Portfolio Project

About the Platform

PestPredict SP is a geospatial predictive intelligence platform engineered to map and forecast infestation risks for both urban vectors and agricultural/forestry pests across the State of São Paulo, Brazil.

By cross-referencing real-time weather data (temperature, relative humidity, and accumulated precipitation) via the Open-Meteo API with bio-climatic thresholds and pest phenology, the application calculates regional susceptibility for key species such as Tityus serrulatus (yellow scorpion), Diatraea saccharalis (sugarcane borer), and major silviculture pests.
